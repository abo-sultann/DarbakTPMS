# Darbak TPMS — الخطة المعتمدة

## V1
### الرئيسية
- 4 إطارات + الاحتياطي.
- PSI كبير، الحرارة أقل بروزًا، الحالة وآخر قراءة.
- لا تعرض بيانات جلسة سابقة كأنها حية.
- اتجاه الضغط: ارتفاع / ثابت / انخفاض.
- مقارنة الإطارات لاكتشاف الانحراف.
- مؤشر صحة النظام والاتصال وتدفق البيانات.

### الحساسات
المواقع: أمامي يسار، أمامي يمين، خلفي يسار، خلفي يمين، احتياطي.
عند اختيار موقع مستخدم يتم تبديل موقعي الحساسين تلقائيًا.

IDs الحالية:
- FRONT_RIGHT: 04028A90
- FRONT_LEFT: 04028B5E
- REAR_RIGHT: 04028AE1
- REAR_LEFT: 04028A57
- SPARE: 04028A77

### التنبيهات
- طبيعي: صامت.
- ملاحظة: Overlay صغير ثم يختفي.
- خطر: صوت + فتح التطبيق + تحديد الإطار والسبب.
- فقدان ضغط سريع: عدة قراءات + PSI/min، وليس Packet منفردة.
- Hysteresis / debounce.
- الحدود قابلة للتعديل.

### الاعتمادية
- Boot auto-start وBackground monitoring.
- Auto reconnect.
- Missing sensor detection مع التفريق عن انقطاع ESP32.
- Watchdog للتطبيق والاتصال وتدفق البيانات.
- Emergency snapshot: PSI + °C + timestamp + PSI/min قبل/بعد الحدث.
- Event log للأحداث المهمة فقط.
- Test Alert للصوت وشاشة الطوارئ.

### التشخيص
Sensor ID، آخر Packet، عدد القراءات، الاتصال، PSI/min.

## V2 بعد بيانات ميدانية
- اكتشاف التسريب البطيء.
- تحليل متقدم للضغط مقابل الحرارة.

## حدود المشروع
لا خرائط، لا GPS، لا Trip features. تطبيق متخصص وخفيف.

## بوابة البناء
لا يبدأ APK الكامل حتى تنجح بوابة قرار الاتصال في `CONNECTION_DECISION.md`.
